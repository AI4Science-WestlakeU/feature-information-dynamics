# Repository contents

This repository is the single working directory for the public code: source,
notebook, configurations, upstream patches, tests, scientific evidence and README assets.
Data, runs, environments, build products and local archives are ignored.

The project page is maintained only in the personal website repository at
`feature-information-dynamics/index.html`. Its assets, bilingual prose and interaction
are edited there and previewed directly there. The code repository links to
https://panjiashu.github.io/feature-information-dynamics/ and does not maintain a
second HTML page or template. The MNIST display exporter produces measured arrays,
not website prose. README GIFs are generated from the website's canonical page.

Historical development files and Git history are retained in a local archive,
not in a second active publication directory. Pending RAE and data evidence remains
uncommitted; existing reproduction limitations still apply.
