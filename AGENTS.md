# Implementation contract

Use did_q01's actual experiment logic as the scientific baseline. Improve public
usability and readability without replacing encoding, objectives, time sampling
or EMA with a common pilot recipe. Preserve the approved Pixel spatial-token fix.
Do not use small-model controlled RAE x-pred experiments as the large-model baseline.

This is a separate local implementation repository. Do not depend on sibling
repositories, private filesystem paths, external classifier checkpoints, or SSH
for public commands. Keep scientific results separate from synthetic fixtures.

Preserve signed risk differences. Use vector squared-error sums for information
integrals, natural logarithms for nats, and explicit finite integration limits.
Never infer Bayes convergence from a plateau, positive edges, or a good plot.

Publish no remote repository, data, or third-party weights until actual execution
and release review are complete. A representative checkpoint verifies only its
own measurement instance. The MNIST teaching example is not a substitute for the
paper's spectral MNIST experiment. Legacy results are not the unified remeasurement.

Run numeric tests and the relevant executable workflow after changing it. Record
hardware, configurations, hashes, and limitations in docs/validation.md. Training
budgets are finite; do not automatically restart the old project's L experiments.
