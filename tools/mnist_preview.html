From ambiguity to identity

At low SNR, several digit classes can match the observation. The unconditional denoiser averages over plausible digits; the class-conditional denoiser averages within one class. As the observation resolves identity, their predictions converge.

These are clean-image predictions at fixed noise levels, not frames from a reverse diffusion sampling trajectory.

From error to information

The gap between unconditional and class-conditional MMSE yields the information density:

\(D_Y(\ln\gamma)=\frac{\gamma}{2}(m_{\varnothing}-m_Y)\)

Integrating this density gives accumulated class information. Integrating the density and normalizing by its finite-range total gives class generation progress.

Class generation progress summarizes accumulated class information over the displayed SNR range. It is not classification accuracy or an individual image’s confidence. The notebook checks the information estimate against label entropy.

Beyond class: chained information decomposition

Compare cumulative conditions: none → class → class + mask → class + mask + Canny. Each adjacent MMSE difference gives an information increment, \(D_k=\frac{\gamma}{2}(m_{k-1}-m_k)\). These sum to the joint density, while their allocation depends on feature order.

This demonstration measures class only. See the paper’s Chained Information Decomposition for the extension.
